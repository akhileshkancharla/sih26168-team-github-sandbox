# Contributing Rules

- Never work directly on `main`.
- One assigned issue normally equals one branch and one pull request.
- Use the exact branch name supplied in the issue.
- Modify only the files listed under Allowed files.
- Do not add dependencies or Actions without written lead approval.
- Do not redesign interfaces, schemas, algorithms or thresholds.
- Run all verification commands after the latest change.
- Link the pull request with `Closes #ISSUE_NUMBER`.
- Never merge your own pull request.
- Never share secrets, credentials, tokens, private data or recovery codes.
- Ask questions in the GitHub issue so the answer remains visible.
