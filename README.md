# SIH26168 Team GitHub Practice Sandbox

This is a disposable training repository for Git, GitHub issues, pull requests,
reviews, automated tests and merge-conflict practice.

It contains no SIH production implementation. The status rules and sample data
are toys created only for collaboration training.

## Mandatory workflow

1. Receive an assigned issue.
2. Synchronize `main`.
3. Create the branch specified by the issue.
4. Change only permitted files.
5. Run the required local checks.
6. Push and open one linked pull request.
7. Wait for CI and lead review.
8. Apply requested changes on the same branch.
9. A lead performs the final squash merge.

Read `CONTRIBUTING.md` and the supplied contributor roadmap before starting.
